# Asset-Sentinel
Industrial AI Ecosystem for Predictive Maintenance.

## Services Overview:
1. **Forecasting Service**: RUL Prediction using TST.
2. **Consulting Service**: RAG-based diagnostics.
3. **Notification Service**: Alerting & Ack handling.
4. **Querying Service**: Text-to-SQL logic.
5. **Reporting Service**: Visualization & Analytics.
6. **Managerial Service**: User & Factory management.
